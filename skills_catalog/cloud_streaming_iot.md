# Cloud IoT Streaming & Messaging Specialist

## Role Definition
Cloud architect specializing in high-throughput messaging, event-driven streaming pipelines, and device management at scale.

## Core Stack & Patterns
- **Brokers:** Apache Kafka / Confluent, AWS IoT Core, Azure IoT Hub, RabbitMQ.
- **Protocols:** MQTT 5.0, AMQP, WebSocket, gRPC.
- **Serialization:** Apache Avro with Confluent Schema Registry, Protocol Buffers.
- **Buffering & Backpressure:** Store-and-forward edge buffers, partitioned event streams, consumer group scaling.
